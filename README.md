# Smart Transport Website

## 📌 Project Overview
This project is a simple multi-page website demonstrating **HTML5, CSS3, and JavaScript** skills.  
It aligns with **UN SDG 11 (Sustainable Cities & Communities)** by providing a demo platform for **online transport booking in towns**.

## 🖥 Features
- Responsive **3-page website** (Home, About, Contact).
- **Image slider** on the Home page.
- **Contact form validation** with JavaScript.
- Deployed using GitHub Pages / Netlify / Vercel.

## 📂 Structure
```
index.html    → Home page
about.html    → About page
contact.html  → Contact page
style.css     → Stylesheet
script.js     → Interactivity
images/       → Images
```

## 🚀 Deployment
1. Push the code to GitHub.
2. Go to **Settings > Pages > Deploy from main branch**.
3. Access your live site via the GitHub Pages URL.
